Catalogue d’ateliers

Tu vas construire une interface qui affiche les ateliers, permet de les filtrer, garde tes favoris après rechargement et charge ses données depuis un fichier JSON.

Dans le dossier du projet, lance npm start et ouvre l’adresse indiquée. Chaque cours est aussi accessible avec npm run cours:01, chaque exercice avec npm run exo:01 et chaque corrigé avec npm run corrige:01. Change le numéro pour passer à l’étape suivante. Arrête le serveur avec Ctrl+C avant de relancer une commande.

À chaque étape, lis et exécute le script de cours, modifie le script de l’exercice, puis compare le résultat avec le corrigé. Observe les erreurs dans la console du navigateur.
